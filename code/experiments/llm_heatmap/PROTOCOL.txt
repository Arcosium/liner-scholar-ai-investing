목적: 논문 표 1의 빈 칸(맥락을 담은 그림 · 학습 없음)을 채운다. 열지도 CNN이 본 것과 같은 열지도를 학습 없이 Haiku에게 보여 주고 받은 점수로 롱숏 포트폴리오를 만든다. 같은 그림에서 학습한 CNN과 학습하지 않은 LLM을 비교하려는 것이다. 차트 이미지 실험(haiku_image_20261028)과 짝을 이룬다.

입력: 종목 하나당 이미지 한 장. HYFE_QTPA hyfe/train_cnn.py 의 heatf 와 같은 48행×60봉 수치(가격 4행·거래량 2행·시간 2행·횡단면 순위 3행·판단 시점 지표 27행·횡단면 순위 지표 10행, 지표는 구간별 학습 집합 평균·표준편차로 표준화 뒤 시그모이드)를 회색조로 그린다(어두움 = 낮음, 밝음 = 높음). 칸 하나 8×10px, 행 이름과 행 묶음 사이 옅은 파랑 간격, 봉 축 표시. 날짜·종목명·가격 수준은 없다. build_heat.py 로 수치를 만들고 구간 D(s0)에서 원 CNN(시드 0) 가중치로 다시 예측해 저장된 예측과의 상관이 0.999를 넘는지 확인한 뒤 render.py 로 그린다. tasks 에 있으나 열지도를 만들 수 없는 (시각, 종목)은 그 시각 순위에서 빼고 건수를 보고한다.

지시문: run.py 의 SYSTEM. 행 정의(지표 정의 문장은 지표 실험 지시문 그대로)와 차트 실험과 같은 질문(같은 시각 다른 종목 평균 대비 14일 상대수익, [-1,1], JSON {"score": x} 한 개), 전략의 성패를 가정하지 말라는 문장.

모델: claude-haiku-5-5, Anthropic Batch API. 추론 끔. 샘플링 기본값. 최대 출력 64토큰. 반복 3회(같은 요청을 독립적으로 세 번).
